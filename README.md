# Saetta pour Windows

Installateurs Windows signés et canal de mise à jour de Saetta.

## Télécharger

[Télécharger la dernière version](https://github.com/FratelliaHolding/Saetta-Releases/releases/latest), puis ouvrir le fichier `Saetta-Setup-<version>.exe`.

Après l’installation initiale, Saetta recherche les mises à jour au démarrage puis toutes les six heures. La nouvelle version est téléchargée automatiquement et installée à la fermeture normale de l’application.

Les anciennes installations utilisant un canal privé nécessitent une installation initiale de la version 3.13.1 ou ultérieure.

Les fichiers `.blockmap` et `latest.yml` sont utilisés par le mécanisme de mise à jour ; ils ne sont pas à installer manuellement.
